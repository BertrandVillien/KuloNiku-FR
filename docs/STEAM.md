# Faire connaître le patch sur Steam

## Canal recommandé

Une fois l’accord des ayants droit obtenu et une release testée, créer un Guide
Steam bilingue ou français est le moyen le plus clair : la page communautaire
de KuloNiku accepte déjà les guides. Le guide doit renvoyer uniquement vers les
releases du dépôt officiel, expliquer restauration et vérification, et ne pas
héberger de fichiers du jeu.

- [Guides communautaires KuloNiku](https://steamcommunity.com/app/3357960/guides/)
- [Fonctionnalités de la communauté Steam](https://partner.steamgames.com/doc/features/community)

Une annonce courte dans les discussions peut ensuite renvoyer vers ce guide,
sans messages répétés ni promesse de support officiel. Un outil communautaire
japonais a déjà été présenté dans les discussions du jeu, ce qui constitue un
précédent pratique mais pas une autorisation juridique.

- [Discussion de l’outil japonais](https://steamcommunity.com/app/3357960/discussions/0/807974496347632869/)

## Workshop

Le Workshop n’est pas un canal disponible par défaut. Il exige une intégration
et une activation par le développeur du jeu. En l’état, le Guide Steam et les
releases GitHub sont donc préférables.

- [Documentation d’intégration du Workshop](https://partner.steamgames.com/doc/features/workshop/implementation)

## Contenu du guide

1. statut non officiel et gratuit ;
2. versions Démo/Complet et plateformes réellement testées ;
3. lien vers la dernière release ;
4. simulation, installation et restauration en trois étapes ;
5. avertissement macOS/antivirus sans demander d’exclusion globale ;
6. lien vers le formulaire de correction ;
7. crédits et procédure de retrait ;
8. rappel que le patch sera archivé si le français devient officiel.
