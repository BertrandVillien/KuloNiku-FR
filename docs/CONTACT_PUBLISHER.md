## English

Subject: Permission request — community French patch for KuloNiku

Hello,

I am volunteering on an unofficial French patch for KuloNiku: Bowls Up! Being
able to translate and play the demo is what convinced me to purchase the full
game.

The project distributes no game file, asset, font, or extracted multilingual
text. It only provides a small open-source tool that backs up and locally
patches a legally installed copy, together with the French CSV and compatibility
fingerprints. It works offline, can be fully restored, and falls back to English
when an unknown game update changes a source string.

Would you allow me to publish this free patch and its French translation on
GitHub, and later introduce it through a Steam Guide? I can give you access to
the repository before publication and follow any credit, notice, restriction,
or takedown requirement you consider appropriate. The project will be removed
or archived upon request and is not intended to compete with a future official
French localization.

Thank you for your work on KuloNiku,
